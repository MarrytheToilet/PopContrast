# Publication figures and tables

From the repository root:

```bash
python -m experiments.figures.build_tables
python -m experiments.figures.publication
```

`build_tables.py` creates seven numerical tables and the matched-baseline paths. `publication.py` creates the single-column full-catalog tradeoff plot, all four LLM intervals and six seed pairs, and the framework's five text overlays. `style.py` retains the pink `#E06C97`, blue `#5B93C9`, font, grid, and background conventions. The framework font and license are in `assets/fonts/`.

Default outputs are `results/tables/` and `results/figures/www2027/`. Set `POPCONTRAST_PUBLICATION_DIR` to an existing manuscript directory to write those assets there. The two source manifests record input hashes; the numerical figure manifest also records every plotted value, dimensions, and output hashes. Text bounds are checked before saving the redrawn figures.

Original diagnostic plots are generated by `python -m experiments.make_figures` using the frozen JSON measurements and small aggregate arrays in `assets/plot_data/`. No GPU, external model, or private manuscript is needed to redraw the public figures.

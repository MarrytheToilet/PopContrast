# README previews

copied from the corresponding current publication outputs after regeneration:

```bash
make figures
cp results/figures/model_seed_evidence.png assets/readme/model_seed_evidence.png
cp results/figures/pareto_single_column.png assets/readme/pareto_single_column.png
```

The full generated figure directory and its numerical inputs remain local and
are ignored by Git.
